## Tekniska specifikationer

| Format | Användning |
|--------|-----------|
| WebP (primärt) | Alla browsers |
| AVIF (fallback) | Moderna browsers (bättre komprimering) |
| Max filstorlek | 200 KB per bild (efter optimering) |
| Färgprofil | sRGB |
| Upplösning | 2x för retina (t.ex. 2400×1800 för en 1200×900 visning) |

## Implementering i Next.js

Bilderna placeras i `/public/images/` och refereras via Next.js `<Image>`:

```tsx
import Image from "next/image";

<Image
  src="/images/hero-drone-powerline.webp"
  alt="Drönare inspekterar kraftledning"
  width={1920}
  height={1080}
  priority // bara för hero/above-the-fold
  className="rounded-2xl"
/>
```

Next.js `next.config.mjs` är redan konfigurerad med `formats: ["image/avif", "image/webp"]`.

## OBS: Alt-texter

Alla alt-texter ska vara beskrivande och **utan personnamn**. Exempel:
- "Drönare inspekterar kraftledning vid solnedgång"
- "Termisk bild av elnätskomponent med synlig värmekoncentration"
- "Operatörsteam förbereder drönare för inspektion" (ej namngivna)
